# Threat model (STRIDE-lite)

Assets: the ledger (spending history), the Anthropic API key, receipt photos, the profile password and recovery key.
Trust boundary: the browser tab ↔ api.anthropic.com. There is no server of ours.

| Threat                               | Vector                                                                         | Control                                                                                                                                                                                                                                                                                    |
| ------------------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Key theft (I)                        | XSS or a malicious script on the origin                                        | CSP `script-src 'self'`; no third-party scripts or CDNs; React escaping; no `dangerouslySetInnerHTML`; session-only key by default                                                                                                                                                         |
| Key theft (I)                        | Shared computer                                                                | Opt-in persistence, one-click clear, UI warning                                                                                                                                                                                                                                            |
| Hostile import file (T/D)            | Crafted JSON: wrong types, huge arrays, prototype keys                         | Size cap, zod schema with bounds, every bill re-reconciled, unknown keys stripped                                                                                                                                                                                                          |
| OCR prompt injection (T)             | Text printed on a receipt instructs the model                                  | Output constrained to a tool schema, validated, shown for human confirmation, never auto-saved                                                                                                                                                                                             |
| Hostile workbook (T/D)               | Crafted `.xlsx`: zip bomb, huge sheets, formulas, macros, spoofed "app" sheets | `.xlsx` only (no `.xlsm`/`.xls`), 20 MB cap, row caps per sheet, formulas never evaluated (treated as invalid), unknown sheets ignored, per-bill schema validation and re-reconciliation, ledger copy wins over file copy for known refs                                                   |
| Formula injection on export (T)      | Item text starting with `=`, `+`, `-`, `@` opened in Excel                     | Written as typed string cells, never as formulas; only the app's own total rows are formulas                                                                                                                                                                                               |
| Hostile image (T)                    | An SVG or other document chosen as a "photo"                                   | Raster-only allow-list (JPEG, PNG, WebP, GIF) at the file input and in code; photos are shown only through `<img>` from a `blob:` URL the page created (an `<img>` never runs script) — CodeQL flagged the `src` flow (alerts 2–3); hardened rather than dismissed                         |
| Device or browser profile theft (I)  | Someone copies IndexedDB or uses an unlocked, shared computer                  | ADR-0008: AES-GCM sealed records, HMAC ids, PBKDF2 (600k) wrapped keys, password and recovery key, idle auto-lock, lock now, non-extractable keys in use, session ends with the tab. Residual: offline guessing of a weak password; script in an unlocked page can use (not read) the keys |
| Account enumeration (I)              | Probing sign-in to learn which emails have profiles                            | Same message and equal work for unknown email and wrong password; email stored only as a hash                                                                                                                                                                                              |
| Lost credentials (D)                 | Forgotten password and lost recovery key                                       | Recovery key issued once, shown with a confirmation step; data is unrecoverable otherwise (stated up front); exported workbook is the backup                                                                                                                                               |
| Real data exposure (I)               | Real bills committed or bundled in a public repo/site                          | ADR-0007: app starts empty, generated demo data only, `check:privacy` hash guard in `verify` and CI, private parity test via `REAL_FIXTURES_DIR`; history rewrite is a separate, consented step                                                                                            |
| Data loss (D)                        | Storage eviction/clearing                                                      | `navigator.storage.persist()`, backup reminder, export                                                                                                                                                                                                                                     |
| Tampering with ledger (T)            | Local user edits IndexedDB                                                     | Records are authenticated (edits and swaps are detected, ADR-0008); deleting or rolling back records is not; the audit log is informational                                                                                                                                                |
| Supply chain (T)                     | Malicious dependency                                                           | Lockfile, `npm ci`, Dependabot, `npm audit`, CodeQL, minimal dependency set (react, dexie, zod)                                                                                                                                                                                            |
| Info disclosure via referrer/framing | Navigation, embedding                                                          | `Referrer-Policy: no-referrer` meta; GitHub Pages cannot set frame headers — accepted, no sensitive action is one click                                                                                                                                                                    |

Residual risk accepted: GitHub Pages cannot send HTTP security headers, so CSP is delivered by `<meta>` (no
`frame-ancestors`, no report-uri).
